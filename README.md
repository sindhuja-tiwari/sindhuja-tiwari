## 🚀 Featured Project

### Hierarchical Navigable Small World

A from-scratch **C++17 HNSW approximate nearest-neighbor search engine** built to explore vector search, graph indexing, concurrency, and performance engineering.

**Highlights**

- C++17 implementation from scratch
- Multi-layer HNSW graph
- Parallel insertion
- SIMD-friendly distance computation
- Configurable `M` and `efConstruction`
- Recall / latency / throughput benchmarking
- Compared against `hnswlib`
- SIFT-1M and GloVe-100 evaluation

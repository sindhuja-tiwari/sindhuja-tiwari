<font color="#94a3b8">

A from-scratch **C++17 HNSW approximate nearest-neighbor search engine**.

</font>

<br>

<img
src="https://github-readme-activity-graph.vercel.app/graph?username=sindhuja-tiwari&bg_color=000000&color=38bdf8&line=0ea5e9&point=ffffff&area=true&hide_border=true"

<br><br>

<a href="https://github.com/sindhuja-tiwari/Hierarchical-Navigable-Small-World">

</a>

</div>

<br>

<table width="100%" bgcolor="#020617">
<tr>
<td>

**Highlights**

- C++17 implementation from scratch
- Multithreaded graph construction
- SIMD distance computation
- Lock-free queries after construction
- HNSW hierarchical graph navigation
- Brute-force ground-truth evaluation
- SIFT1M and GloVe-100 benchmarks
- Comparison against `hnswlib`
- Recall / QPS / latency measurements
